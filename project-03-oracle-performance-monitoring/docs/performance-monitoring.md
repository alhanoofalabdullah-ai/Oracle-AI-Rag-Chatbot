# Performance Monitoring

## Objectives

The monitoring platform focuses on:

1. Availability
2. Performance
3. Capacity
4. Database activity
5. SQL efficiency

## Key Metrics

### SQL

- Elapsed time
- CPU time
- Executions
- Buffer gets
- Physical reads
- Rows processed

### Sessions

- Active sessions
- Long-running sessions
- Sessions by user
- Wait events

### I/O

- Physical reads
- Physical writes
- File activity

### System

- Oracle system metrics
- Database statistics
