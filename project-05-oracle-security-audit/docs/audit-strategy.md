# Audit Strategy

## Objective

The objective is to provide visibility into database
security events.

---

## Events

The platform monitors:

- Successful logins
- Failed logins
- Database actions
- Object access
- Privileged activity

---

## Failed Authentication

Repeated failed login attempts can indicate:

- Incorrect credentials
- User error
- Automated authentication problems
- Credential attacks
- Suspicious activity

These events should be investigated based on the
organization's security procedures.

---

## Audit Review

Security teams should periodically review:

- High-risk accounts
- Privileged access
- Failed logins
- Unexpected hosts
- Administrative operations
- Changes to security configuration

---

## Retention

Audit retention should be aligned with:

- Organizational policy
- Regulatory requirements
- Security requirements
- Storage capacity
- Incident response requirements
