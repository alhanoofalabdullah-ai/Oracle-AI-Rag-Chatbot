# Monitoring Strategy

## Availability

The application monitors:

- Database open mode
- Database role
- Instance status
- Startup time

## Capacity

The application monitors:

- Tablespace size
- Used space
- Free space
- Utilization percentage

## Activity

The application monitors:

- Total sessions
- Active sessions
- Sessions by user
- Sessions by machine

## Performance

The application monitors:

- System metrics
- Top SQL
- CPU time
- Elapsed time
- Buffer gets
- Physical reads
- Wait events
